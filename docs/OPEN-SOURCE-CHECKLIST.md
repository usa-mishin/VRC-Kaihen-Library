# オープンソース公開前チェック

## 公開しないもの

- Codex、Claude、Cursor、IDE の個人設定
- `.env`、API キー、アクセストークン、パスワード、接続文字列
- コード署名証明書と秘密鍵（`.pfx`、`.p12`、`.pem`、`.key` など）
- BLM・本アプリのデータベース、ユーザー設定、キャッシュ、ログ、診断画像
- BOOTH のダウンロード商品、Unity プロジェクト、生成済みインストーラー
- PC のユーザー名を含む絶対パスや、公開を意図しないメールアドレス

これらは `.gitignore` で除外している。ただし、`.gitignore` は過去にコミット済みのファイルを非公開へ戻す機能ではない。

## 公開直前の確認

1. `git status --short --ignored` で、ローカル生成物が追跡対象になっていないことを確認する。
2. `git ls-files` で、公開予定の全ファイルを確認する。
3. 秘密情報スキャナーをGit履歴全体へ実行する。
4. `git log --format="%an <%ae>" --all` でコミット作者名とメールアドレスを確認する。
5. `git remote -v` で、公開してよいアカウント名・組織名だけが含まれることを確認する。
6. 公開リポジトリに適用するライセンスを選び、`LICENSE` を追加する。

## Git履歴に情報が含まれていた場合

現在のファイルから削除しただけでは、過去のコミットから引き続き閲覧できる。公開前に履歴を書き換え、すべてのリモートブランチとタグを置き換える必要がある。履歴の書き換えはコミットIDを変更し、既存クローンとの互換性を失わせるため、バックアップと影響範囲を確認してから行う。

メールアドレスを非公開にしたい場合は、今後のコミットにGitHubのnoreplyアドレスを使用する。過去のコミットに含まれるアドレスは、別途履歴の書き換えが必要になる。

## 2026-08-29 監査結果

- 現行の追跡対象から、個人PCの絶対パス、メールアドレス、秘密鍵、アクセストークン、パスワード、ユーザーデータベース、商品ファイル、UnityPackage、診断画像、インストーラー生成物が除外されていることを確認した。
- `.codex-*`、診断物、ビルド生成物、ユーザーデータ、署名関連ファイルは `.gitignore` の対象になっている。
- リポジトリ固有のAI支援設定である `AGENTS.md` はローカル利用のためファイルを残すが、Gitの追跡対象から外し、今後も無視する。
- 現在のGit作者メールはGitHubのnoreplyアドレスになっている。ただし既存履歴には個人メール、過去のローカル絶対パス、旧MSIX Publisher名、`AGENTS.md` が含まれる。
- 既存履歴をそのまま公開したり、現在の非公開リポジトリを公開へ切り替えたりしない。公開時は、監査済みの現行スナップショットだけを新しい履歴の初回コミットにし、新規公開リポジトリへPushする。
- 追跡中の最大バイナリはアプリ用画像で約431KBであり、商品データや配布バイナリは履歴に存在しない。
- NuGetの既知脆弱性および非推奨パッケージ検査は該当なし。第三者ライセンスは `THIRD-PARTY-NOTICES.md` に記載した。
- `runFullTrust` はWinUIデスクトップアプリとしてローカル商品ファイル、Unity、エクスプローラーを扱うために必要であり、アプリ内のポリシーページで用途を説明する。

公開用の新規履歴を作成した後、公開直前に本チェックリストの1～6と秘密情報スキャンをその新規履歴へ再実行する。
