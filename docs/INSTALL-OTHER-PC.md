# 他の PC へのインストール手順（テスト配布）

この手順は、自己署名証明書で署名したテスト版 MSIX 用です。信頼できる相手から直接受け取った配布物だけに使用してください。

## 必要条件

- Windows 10 19041 以降、または Windows 11
- x64 CPU
- BOOTH Library Manager がインストール済みで、商品データを読み込み済みであること
- 証明書の登録時に管理者権限を使用できること

## 1. ZIP を展開する

ZIP を右クリックして「すべて展開」を選びます。ZIP の中から直接ファイルを開かないでください。

展開後、少なくとも次の2ファイルがあることを確認します。

- `VrcKaihenLibrary_1.0.4.0_x64.cer`
- `VrcKaihenLibrary_1.0.4.0_x64.msix`

## 2. 署名証明書を信頼する

1. `.cer` ファイルをダブルクリックします。
2. 「証明書のインストール」を選びます。
3. 保存場所は「ローカル コンピューター」を選びます。
4. 管理者権限の確認を許可します。
5. 「証明書をすべて次のストアに配置する」を選びます。
6. 「参照」から「信頼されたユーザー」を選びます。
7. 完了まで進み、「正しくインポートされました」と表示されることを確認します。

自己署名証明書を信頼する操作は、この証明書で署名したアプリを信頼する意味を持ちます。配布元とファイルが正しいことを確認してから実行してください。

## 3. アプリをインストールする

1. `.msix` ファイルをダブルクリックします。
2. 発行元が `usa-mishin`、アプリ名が「VRC改変ライブラリ」であることを確認します。
3. 「インストール」を選びます。
4. 完了後に「起動」を選びます。

App Installer が表示されない場合は、Microsoft Store で「アプリ インストーラー（App Installer）」を更新してから再試行します。

## 4. 初回起動を確認する

- BLM DB: `%APPDATA%\pm.booth.library-manager\data.db`
- 本アプリ DB: `%LOCALAPPDATA%\VrcKaihenLibrary\library.db`

商品一覧が表示されればインストール完了です。BLM DB がない場合、本アプリは商品を読み込めないため、先に BOOTH Library Manager を起動して商品情報を準備してください。

## 更新とアンインストール

- 同じ署名者で、より大きい版番号の MSIX を開くと更新できます。
- アンインストールは Windows の「設定 > アプリ > インストールされているアプリ」から行います。
- アンインストール後も本アプリ DB が残る場合があります。ユーザー設定を完全に消す必要がある場合だけ、バックアップ後に `%LOCALAPPDATA%\VrcKaihenLibrary` を手動で削除してください。

## トラブル時

- 「証明書を検証できません」: 証明書を「現在のユーザー」ではなく「ローカル コンピューター > 信頼されたユーザー」に入れたか確認します。
- 「このアプリ パッケージはサポートされていません」: Windows の版とCPUが要件を満たすか確認します。
- 同じ版番号が既にある: 既存版をアンインストールするか、より新しい版番号の配布物を使用します。
- 旧 `VrcKaihenManager` が残る: MSIX identity が異なるため別アプリです。不要なら旧版を Windows の設定からアンインストールします。
