# プライバシーポリシー

最終更新日: 2026-08-29

VRC改変ライブラリ（BOOTH Library Manager拡張）は、BOOTH Library ManagerがPC内に保存した情報をローカルで整理する非公式デスクトップアプリです。BOOTHおよびBOOTH Library Managerの運営元との提携関係はありません。

インストーラーまたはアプリ初回起動時に、以下のローカルデータ参照について説明し、ユーザーが明示的に同意した後だけ、BOOTH Library ManagerがPC内に保存した商品情報を読み取ります。同意しない場合、その商品情報へアクセスせずアプリを終了します。同意した事実と説明の版番号だけをPC内へ保存します。

同意はアプリ内の「ポリシー」からいつでも取り消せます。取り消すと同意記録と画面上の商品情報を消去してアプリを終了し、次回起動時に説明を再表示します。BOOTH Library Managerが保存した商品情報、商品ファイル、本アプリの分類設定は削除しません。

EXE版をアンインストールした場合は、インストーラーが保存したレジストリ上の同意記録を削除します。本アプリの設定DBは従来どおり保持されますが、再インストール時にはインストーラーで改めて説明と同意を表示します。

## 読み取る情報

- 商品名、ショップ名、商品説明、タグ、BOOTH商品ID
- 購入・ダウンロード済みバリエーション、登録・更新日時
- BLMの商品保存先、ファイル名、フォルダー名、更新日時
- ユーザーがUnityインポートを選んだUnityPackageの内容
- インポート操作時に選ばれた起動中Unity Editorのプロジェクト場所

氏名、住所、メールアドレス、パスワード、Cookie、ブラウザ履歴、クリップボードを収集する機能はありません。

## 保存する情報

分類、アバター識別タグ、対応設定、未購入アバター、Unityインポート先、表示設定を `%LOCALAPPDATA%\VrcKaihenLibrary\library.db` に保存します。分類フォルダー向けに再生成したUnityPackageは、BLMライブラリ直下の `.VrcKaihenLibraryImportCache` に保存します。

## 通信

独自サーバー、広告、利用状況解析、テレメトリー、クラッシュ自動送信はありません。サムネイル表示のため、HTTPSのBOOTH公式ドメインへ画像を要求する場合があります。その際、一般的なWeb通信と同様に画像配信元へIPアドレスとアクセス日時が伝わる可能性があります。バージョン情報をクリックした場合だけ、GitHub Releasesの公開APIへ最新版確認の通信を行い、リリースページを既定ブラウザーで開きます。商品ページはユーザー操作時だけ既定ブラウザーで開きます。

## 変更と削除

BLM DBは読み取り専用です。Unityインポートを選んだ場合は、対象Unityプロジェクトの`Packages`へ連携スクリプト、`Library`へ一時要求を作成します。重複整理は確認後だけ実行し、古いフォルダーをごみ箱へ移します。アンインストールでは設定DB、キャッシュ、Unity連携ファイルを自動削除しません。

## 問い合わせ

問題や懸念は、配布元のGitHubリポジトリのIssueで報告してください。

本アプリのアイコンは独自に制作したもので、BOOTH公式のロゴ・アイコンを収録したものではありません。BOOTHの名称は連携対象を説明する目的で使用しています。
